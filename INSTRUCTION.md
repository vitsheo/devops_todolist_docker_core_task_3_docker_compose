# DevOps TodoList Docker

Інструкція для запуску та зупинки контейнерів проєкту.

## Запуск додатка
Щоб зібрати та запустити всі сервіси у фоновому режимі (detached mode), виконайте команду:
```bash
docker-compose up -d
```

## Зупинка додатка
Щоб зупинити роботу всіх контейнерів та видалити їх, виконайте:
```bash
docker-compose down
```
